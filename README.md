# Damaris Foundation for Premature Infants — Rebuild

Clean, responsive multi-page GitHub Pages website.

Pages: Home, About, Mission & Vision, Objectives, Our Team, Support, Contact.

### Interactive features
- Responsive mobile navigation
- Home feature cards with changing detail panel
- 15 objectives open in a modal with Previous/Next navigation
- Team profiles open in a modal
- Direct call, WhatsApp, email and social links

### Supplied assets
Place the exact foundation logo and team photos in `assets/` with the filenames used by `script.js`. The build currently includes a text-based D logo fallback so the site still renders without the logo file.

### GitHub Pages
Upload the contents of this folder to the repository root. In GitHub: Settings → Pages → Deploy from branch → main → /(root).
